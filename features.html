功能架构总览

一个会自我进化、可人工干预进化的《无尽的拉格朗日》AI 战术顾问 · 本地离线语音 · 知识库驱动

1️⃣ 核心对话引擎
🛰️
多 Agent 并行检索
舰队配置 / 舰船数据 / 战斗机制 / 讲解范例 4 个子代理并行检索知识库，主检索兜底，即问即答。
检索
🔧
7 个工具
知识库检索、舰船精确查询、战斗模拟、联网搜索、提问澄清、自主建工具、自主建Skill——AI 按需调用。
工具
🔬
FACT-AUDIT 质检
主张拆解→证据检索→多裁判辩论→五层审计→量化评分→链状修正；第2次仍不合格即强制放行，防死循环。
质检
🪄
计划模式 / 普通模式
普通模式直接回答；计划模式先出执行计划书、用户批准后才执行。顶栏一键切换。
模式
2️⃣ 自我进化（Agent 自主）
🧬
经验 Skill 沉淀（自动）
每轮对话结束后，AI 自动判断这段对话是否有可复用经验（配队思路/回答技巧/稳定偏好），有则沉淀为 Skill，无则静默。
自动
🧰
自主创建工具
AI 判断现有工具不够用时，自行写代码创建新工具，经「语法编译 + LLM 逻辑审查」自检通过即激活，不通过自动修复。
自动
🎯
Skill 按需注入
相关 Skill 命中关键词自动注入本对话；不相关不注入（防 token 膨胀）；画像只注入精简摘要。
自动
3️⃣ 用户干预进化（人工）
👍👎
点赞 / 点踩反思
对回答点赞/点踩可填理由，AI 反思整段对话，沉淀经验 Skill、更新用户画像。你越用，它越懂你。
人工
✍️
手写 Skill
在技能/工具页手动写一个 Skill（名称+摘要+关键词+全文），创建后相关对话自动注入。
人工
💬
对话直接创建
直接说「把这个保存成 Skill」，AI 就调用 create_skill 帮你创建。
人工
⚡
斜杠命令强制干预
/skill、/工具、/压缩、/回溯、/重启、/clear 等，强制注入、强制调用、强制操作。
人工
4️⃣ 对话管理
🌿
分叉对话
在任意消息处分叉，快照生成一个全新独立会话，原对话保留。
对话
↩️
回溯 / 重启
回溯=删除最新一轮问答；重启=回溯后原样重发那条提问。
对话
📎
@ 引用上下文
输入 @ 选中历史会话，其上下文注入本次提问供 AI 参考。
对话
🧹
/clear 清空会话
独立命令清空当前会话全部内容回初始。
对话
5️⃣ 输入能力
🎤
本地语音输入
浏览器内本地 ASR（sherpa-onnx WASM），麦克风→文字，纯离线不依赖云端。
本地
🔊
本地文本朗读
本地 TTS 合成中文朗读，纯离线。
本地
📎
文件 / 图片附件
文本文件读入；图片可配视觉模型识别内容再分析。
输入
🌐
联网搜索
搜索代理→Tavily→免key Bing 多级降级。
输入
6️⃣ 知识库
📚
双知识库检索引擎
第一知识库（47个md：舰船数据/战斗机制/实例/黑话）+ 第二知识库（备份精炼），TF-IDF 语义检索 + LRU缓存。
知识库
🗂️
开发中心
批量清洗→语义分块→实体抽取→冲突仲裁，产出清洗文档/父子块/知识图谱/勘误报告。
知识库
7️⃣ 模型生态
🧿
智谱 GLM 免费默认
glm-4.7-flash 永久免费、200K 上下文，开箱即用；直连或云端代理两种模式。
免费
🔑
多模型管理
添加多个 API/模型（DeepSeek/OpenAI/智谱等），聊天内一键切换。
配置
🔄 一次对话的完整流程
用户提问→4个子代理并行检索→主检索+联网搜索→组装【系统提示词+知识库资料+相关Skill+对话历史】→Agent主循环（可调7工具/可提问暂停）→FACT-AUDIT质检→最终回答+来源标注

自我进化路径：对话结束→自动反思→沉淀Skill/更新画像→下次相关对话自动注入
人工进化路径：👍👎 / 手写Skill / 对话直接创建 / 斜杠命令→Skill库→按需注入
💡 一句话理解：AI 对话用知识库+工具+质检保证准确；自进化与人工干预让 AI 越用越懂你；本地语音离线随时可用。
📌 入门：先到 ⚙️设置 确认模型，再到 🤖AI对话 提问；想沉淀经验就👍、想干预就✍️手写Skill或💬叫AI保存。
